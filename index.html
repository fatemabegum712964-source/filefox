FAQ

Questions?

Is FileFox free? +

The tools in this version are designed to be free to use.

Do I need to install an app? +

No. FileFox is designed to work from a modern web browser.

Does DSLR Look really turn a photo into a DSLR photo? +

No camera can be recreated by simple browser filters. DSLR Look is a photo-enhancement tool that adjusts color, contrast, brightness and local clarity.

Does Background Remover work on every image? +

This lightweight version works best with simple, relatively uniform backgrounds. Complex hair, transparent objects and busy backgrounds need a dedicated segmentation model.
